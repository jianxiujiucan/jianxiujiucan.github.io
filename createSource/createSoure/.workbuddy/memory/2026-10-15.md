# 2026-10-15

## 主页面新增「生成图片」按钮（A4 出图）

- 需求：主页面加按钮，把 `.page` 内容用 canvas 生成 A4 比例图片。
- 实现：
  - 新增 `src/utils/a4Layout.ts`：纯函数计算 A4 布局（210:297，默认 300dpi = 2480×3508，页边距比例 0.05，contain 等比缩放居中）。Node 直跑单测全部通过。
  - 新增 `src/utils/a4Image.ts`：`exportElementToA4Image(el)`，html-to-image 的 `toCanvas` 渲染 DOM → 绘制到 A4 画布 → PNG blob。
  - 改写 `src/App.vue`：右上角固定「生成图片」按钮 + 生成中状态 + 预览弹层（尺寸信息、下载、关闭、ESC）。
  - 依赖：`pnpm add html-to-image`（1.11.13）。
- 关键坑（重要经验）：html-to-image 克隆节点会把**已用样式**原样内联（`max-width: 820px`、`margin: 0 auto` 的具体像素值、子元素的 used width）。若再叠加 `box-sizing: border-box`，max-width 语义变化会把盒子二次收紧，内联边距像素又会把内容推出画布右侧被裁。修复：根克隆节点显式 `style: { boxSizing: 'border-box', maxWidth: 'none', margin: '0' }`。另：显式传 height 时要用 `Math.max(offsetHeight, scrollHeight)` 捕获溢出内容（本页 .page 固定 1201px 高但内容溢出 77px）。
- 验证方式：Edge headless + CDP（本沙箱无法常驻 GUI 进程，需在同一条 bash 命令内启动浏览器→跑 CDP 脚本→kill）。截图对比实时页面与生成图，确认渲染一致、无控制台报错。
